# アウトドア文化

[← 企画概要](../overview.md)

## この世界におけるアウトドアの位置づけ [確定]

現実世界のキャンプが「不便さを楽しむ」ものであるように、この世界のアウトドアは**魔法社会の過剰最適化から距離を取る行為**として価値を持つ。

単なる野外趣味ではなく、魔法に満ちた都市生活からの「デトックス」としての意味がある。

## アウトドアの価値構造 [確定]

| 都市（魔法社会） | 自然（アウトドア） |
|-----------------|------------------|
| 最適化・効率 | 不確実性・偶然 |
| 魔法による間接体験 | 身体で世界に触れる |
| 情報過多・感覚鈍化 | 五感の回復 |
| 正解・最短ルート | 非効率の許容 |
| 魔法ノイズ | 静けさ・解放 |
| 加工された快適さ | 本物の火、水、食事 |

## 自然環境での魔法 [有力案]

- 自然の中では魔法が**不安定**になる
- 環境エネルギーが乱れているため、制御が難しい
- 使いすぎると逆に疲れる（都市の数倍の生体エネルギーを消費する？）
- あえて魔法に頼らない時間が、心身の回復になる

> **物語的機能**: 自然での魔法の不安定さが、「手を使う」「身体で感じる」行為を必然にする。これがテーマと直結する。

## アウトドアの具体的な活動 [有力案]

主人公が楽しむ（または直面する）活動:

### 確実に描くもの
- 焚火（火起こしから）
- 野外調理（食材調達含む）
- 徒歩での移動・ハイキング
- 野営・テント設営

### 描く可能性が高いもの
- 狩猟（食材としての獣肉）
- 釣り
- 山菜・野草の採取
- 天候の読み・対応

### 描くかもしれないもの
- 登山
- 川下り
- 星空観察
- 温泉（自然湧出）

## アウトドアの社会的認知 [未確定]

- アウトドアはこの世界でどれくらいメジャーな趣味か？
  - 案A: ニッチな趣味。「変わった人がやること」
  - 案B: 一定の人気はある。健康志向の一環として認知
  - 案C: 近年ブーム化している（現実のキャンプブームに相当）
- アウトドア用品の市場は？魔法道具と非魔法道具のどちらが主流？
- アウトドアガイドのような職業はあるか？

> **設計上の注意**: アウトドアがあまりにメジャーすぎると、主人公の「距離を取る」感覚が薄れる。ニッチ寄りが物語としては機能しやすいが、あまり奇異に見せすぎると読者が入りにくい。案Bあたりが安全か。
