# 魔法体系

[← 企画概要](../overview.md)

## 基本原則 [確定]

- 魔法は存在するが、錬金術のような万能超常ではない
- 物理法則にある程度則る
- 火・水・風・身体補助など、現実のエネルギーや物理現象の延長として機能する
- 無から何かを生み出すことはできない

## 習得と普及 [確定]

- 日常魔法は一般教養レベルで習得されている
- 義務教育を真面目に受け、高等教育を少しかじれば、簡単な魔法を一つくらい使えるのが一般的
- 習得は「才能 × 訓練」で決まる
- 魔法が使えない人がいても、迫害や差別の強い社会ではない
- 魔法の有無は人生の一要素にすぎない（眼鏡をかける/かけないくらいの温度感）

## エネルギー源 [有力案]

**方向性**: 「マナのような完全架空エネルギー」ではなく、現実寄りのモデル。

**有力案: 生体エネルギー × 環境エネルギーのハイブリッド**
- 人間は少量の生体エネルギーを「触媒」として使う
- 周囲の熱・水分・圧力差などの環境エネルギーを操作する
- 魔法は環境条件に影響される

### このモデルの帰結

| 環境 | 魔法の使いやすさ | 理由 |
|------|----------------|------|
| 都市 | 使いやすい | エネルギーが整備・安定している |
| 自然 | 使いにくい | エネルギーが乱れ、不安定 |
| 極端な環境（砂漠・深山） | 非常に困難 | エネルギーの偏りが激しい |

> **設計意図**: この制約がアウトドアとの相性を良くする。自然では魔法に頼れない → 身体感覚の回復 → テーマとの一致。

### 要検討事項

- [ ] 生体エネルギーの消費はどう体感されるか（疲労？空腹？集中力低下？）
- [ ] 環境エネルギーは「見える」のか「感じる」のか
- [ ] 魔法の使いすぎによる副作用の具体像
- [ ] 都市でエネルギーが安定している理由（インフラ整備？自然に？）
- [ ] 「魔法が不安定」の具体的な描写方法

## 魔法の分類 [未確定]

現時点では大分類のみ。詳細は今後詰める。

| 系統 | 概要 | 日常利用の例 |
|------|------|------------|
| 火系 | 熱エネルギーの操作 | 調理の火加減調整、暖房 |
| 水系 | 水分・湿度の操作 | 洗浄、農業、飲料水確保 |
| 風系 | 気流・圧力差の操作 | 換気、乾燥、移動補助 |
| 身体補助系 | 体内エネルギーの調節 | 体力強化、疲労回復、集中力向上 |

### 未確定の論点

- 上記4系統で十分か。地・光・音などは必要か
- 系統間の組み合わせ（複合魔法）は可能か
- 専門職レベルの高度な魔法はどこまで描くか
- 攻撃用途の魔法はこの世界でどう位置づけられるか（軍事？スポーツ？）
