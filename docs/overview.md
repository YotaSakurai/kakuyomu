# 企画概要

[← README](../README.md)

## 作品コンセプト

**一行コンセプト**: 魔法で最適化された社会に疲れた知的労働者が、魔法の通じない自然の中で人間の感覚を取り戻していく静かな物語。

**ジャンル**: 静かな再生系 × 魔法社会 × アウトドア

**掲載先**: カクヨム

## 方向性 [確定]

- バトルや成り上がり中心ではなく、**回復・再生・発見**が主題
- 平和な社会が舞台。現代日本の先進国的な空気感がベース
- 世界の魅力は「魔法が普及した便利な社会」と「そこから距離を取る自然・アウトドア」の対比
- 大きな悪役や世界破滅の危機は不要
- 小さな問題（天候、火起こしの失敗、食料調達、人との出会い、価値観の違い）が物語を動かす
- 解決は穏やかで、静かな満足感が積み上がる構造

## トーン [確定]

- 過度にラノベ風へ寄せすぎず、静かな文学性とエンタメ性の中間
- 「何かを倒す」のではなく、「自分の感覚を取り戻す」方向の面白さ
- 五感描写を重視し、読者にも「体験」を届ける文体を目指す

## 読者体験の設計 [有力案]

読者が得るべき体験:
1. **没入感** — 自然描写・五感描写で「自分もそこにいる」感覚
2. **安心感** — 脅威のない世界で穏やかに読み進められる
3. **再発見** — 日常で忘れていた感覚を思い出す
4. **小さな満足** — 各話の終わりに静かな充足感がある
