# 未決事項・優先論点

[← 企画概要](../overview.md)

## 優先度: 高（1話プロット前に決めるべき）

### Q1. 主人公の具体的プロフィール
- 名前、年齢、性別、一人称
- これが決まらないと文体・語り口が定まらない
- **関連**: [主人公](../characters/protagonist.md)

### Q2. 主人公の職業
- 「魔法寄りの知能職」の具体像
- 職業が物語の起点（疲弊の原因）になるため重要
- 候補: 魔法技術の品質管理、魔法式の最適化エンジニア、魔法関連のコンサルタント
- **関連**: [社会構造](../world/society.md)

### Q3. 第1話の舞台と状況
- 主人公はどこへ行くのか（山？森？川辺？）
- 季節は？（描写の質に直結）
- 単独行の前提で良いか？
- **関連**: [アウトドア文化](../world/outdoor-culture.md)

### Q4. 魔法エネルギーの消費体感
- 生体エネルギーを使うとどうなるか（疲労？空腹？集中力低下？）
- 自然での不安定さは具体的にどう描写するか
- **関連**: [魔法体系](../world/magic-system.md)

### Q5. 物語の縦軸（シリーズ構造）
- 1話完結のエピソード集か、一貫した成長物語か
- 1クール（12話前後）のゴールは何か
- 読者を引きつけるフック（謎・目標・約束）はあるか

## 優先度: 中（序盤数話の間に固めればよい）

### Q6. サブキャラクターの設計
- アウトドアで出会う人々の類型
- レギュラー化するキャラは何人くらい必要か
- 主人公との関係性のバリエーション

### Q7. 都市パートの描写量
- 都市と自然の比率（7:3？ 5:5？ 3:7？）
- 都市パートで何を描くか（仕事？日常？出発準備？）

### Q8. アウトドアの社会的認知度
- ニッチ趣味か、一定の人気があるか
- 主人公は「変わった人」扱いされるのか
- **関連**: [アウトドア文化](../world/outdoor-culture.md)

### Q9. 食事描写の方針
- 食事は重要な要素になりそうだが、どこまで詳細に描くか
- レシピ的な具体性を持たせるか、雰囲気重視か
- この世界の食文化は現実とどう違うか

### Q10. 世界の固有名詞体系
- 地名、人名、魔法用語のネーミングルール
- 日本語ベース？ 架空言語？ 混合？
- カクヨム読者層を考えると、読みやすさ優先が安全

## 優先度: 低（中盤以降で決めても間に合う）

### Q11. 狩猟の扱い
- 狩猟描写はどこまでリアルにするか
- 動物愛護的な配慮はどの程度必要か
- この世界における狩猟の社会的位置づけ

### Q12. 季節の進行
- 物語内で季節は進むか
- 進む場合、どのペースか（1話＝1回のアウトドア？）

### Q13. 魔法の詳細分類
- 4系統以外の魔法は必要か
- 専門職レベルの魔法描写は必要か
