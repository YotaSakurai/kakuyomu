あらすじ
かつて世界を救った勇者・橘 光司（たちばな こうじ）は、魔王を倒した翌日に知らされる──「勇者活動にかかった経費32億ゴルド、勇者本人に請求します」。

冒険中に壊した橋、焼いた森、吹き飛ばした城壁──すべてに損害賠償が発生していた。破産寸前の光司に届いたのは、意外にも魔王城・経理部からの採用通知。

「お前の破壊行為の損害額を、お前自身に計算させてやる」──復活した魔王・ゼルドリスは、勇者を殺すのではなく雇うことで復讐しようとしていた。

しかし経理部で働き始めた光司が見たものは、ブラックすぎる魔王軍の内部事情だった。水増し請求する幹部、闇予算で私腹を肥やす四天王、そして魔王城の財政は実質破綻寸前。

かくして元勇者は、電卓と帳簿を武器に、魔王軍の財政再建に挑む。敵だったはずの魔王とバディを組み、腐敗した幹部を監査で斬り、そして二人は気づく──

この世界の本当の敵は、剣では倒せない。
主要キャラクター
主人公
橘 光司（たちばな こうじ）
24歳男性。元勇者。剣聖級の実力者だったが、冒険中の経費問題で全財産を失う。実は孤児院育ちで数字に強く、そろばん塾に通っていた過去がある。「剣より電卓のほうが人を救える」と本気で信じ始める。
魔王
ゼルドリス
外見年齢30歳。第147代魔王。勇者に敗北後、「武力では人間に勝てない」と悟り、経済戦争による支配を画策。しかし実態は自軍の汚職に頭を抱えている苦労人。先代魔王（父）の浪費のツケを背負っている。
経理部副部長
リリス・フォン・シュヴァルツ
外見年齢25歳のサキュバス。経理部を実質的に仕切るキャリアウーマン。冷徹に見えるが、経理部員たちを家族のように守る。300年間経理部を守り続けている長寿種。
四天王筆頭
ガルドス
魔王軍の最高幹部。軍事予算の8割を握り、闇予算で私腹を肥やしている──ように見えるが、実は戦死した部下の遺族を私的に支援するためだった。
王国側キャラ
アリア
22歳女性。光司のかつての仲間で元魔法使い。現在は王国財務省勤務。王国側にも巨大な不正会計があることに気づき始める。シリーズ「広報部」の主人公候補。

魔王城の部署シリーズ
#タイトル案部署主人公状態
1魔王と勇者の経理部経理部元勇者・光司本作
2魔王城の人事部は勇者を採用したい人事部元僧侶構想中
3魔王軍・広報部の魔法プレゼン術広報部アリア（元魔法使い）構想中
4補給部隊は今日も残業兵站部元盗賊構想中
5魔王城・総務部の最終決算総務部全員集合完結編
シリーズ設計：各作品は独立して読めるが、クロスオーバーキャラと「大決算」イベントで繋がる。完結編「総務部」で全視点が統合される羅生門方式。
セールスポイント
1. 剣ではなく電卓で戦う異世界もの──会計・監査が武器。「お仕事×異世界」のブルーオーシャン
2. 魔王×勇者のバディもの──敵同士がパートナーに。信頼関係の構築がエモい
3. 部署シリーズの拡張性──人事部・広報部・兵站部とスピンオフ展開可能
4. コメディ×シリアスの二層構造──表面はお仕事コメディ、底には戦争経済という社会派テーマ
5. 毎話の爽快感＋全体の陰謀──1話ごとに不正を暴く満足感と、長期の謎を両立
