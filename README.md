# 静寂の焚火（仮題）

**ジャンル**: 静かな再生系 × 魔法社会 × アウトドア
**プラットフォーム**: カクヨム
**ステータス**: 企画・世界観構築フェーズ

## 概要

魔法が日常に浸透した先進的な社会。便利さに最適化された都市生活に疲弊した主人公が、魔法の効かない自然の中で「ちゃんと生きている感覚」を取り戻していく物語。

バトルや成り上がりではなく、**回復・再生・発見**を主題とした、静かな満足感の積み上がる作品を目指す。

## テーマ

- 人間は効率だけでは満たされない
- 正解じゃない時間の価値
- 人間らしさの回復
