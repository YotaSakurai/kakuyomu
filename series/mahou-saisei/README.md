## あらすじ

魔法が日常に溶け込んだ先進国的社会。火も水も温度調節も、基礎魔法で事足りる時代。

主人公は都会で知的労働に従事する魔法使い──偏差値60程度の、特別ではないが平均よりは上の実力者。最適化・高精度・正解志向の日々に疲弊した彼（彼女）は、ある週末、魔法の効きにくい山林でソロキャンプを始める。

火は自分で起こす。水は川から汲む。食材は自分で調達する。不便で、非効率で、正解がない。──だからこそ、五感が蘇る。

大きな敵はいない。世界の危機もない。あるのは天候の変化、火起こしの失敗、偶然の出会い、価値観のすれ違い。そして、静かに積み上がる「ちゃんと生きている」という感覚。

## セールスポイント

1. 「魔法があるのにあえて使わない」という逆説的な世界観の新鮮さ
2. バトルや成り上がりに頼らない、五感と生活感で読ませる物語
3. 現代人の疲弊に重なるリアルな共感装置（魔法社会 ≒ デジタル社会）
4. アウトドア描写の具体性と、それを支える魔法設定の整合性
5. 「正解のない時間」をテーマにした、読者自身の回復体験
