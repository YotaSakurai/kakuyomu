## 職業：魔法調律師

### 仕事の概要（確定）
都市の魔法インフラ（空調・照明・交通・通信など）のエネルギー調律を行う技術職。魔法回路の出力を最適な状態に整え、ズレを検出・修正する。

### 業務の具体像

| 要素 | 内容 |
|------|------|
| 日常業務 | ビル・施設の魔法回路の定期調律、異常検出、出力調整 |
| 求められる能力 | 魔法エネルギーの微細な揺らぎを感じ取る感度、精密な制御力 |
| 疲弊の形 | 一日中、微細なエネルギーの揺らぎに神経を研ぎ澄ませ続ける消耗。0.1の誤差も許されない精密作業の連続 |
| 偏差値60の位置 | 一般的なビル・施設の調律は十分こなせる。大規模施設（空港・中枢インフラ等）は65〜70以上が必要 |
| 仕事のプライド | 都市の快適さを支えている実感はある。技術的には有能。ただし、それが充足感になっていない |

### 調律師の仕事が物語に与える効果

1. **構造的対比**: 「魔法を調律する仕事」の人が「調律されていない自然」に向かう
2. **感覚の説得力**: 職業的に訓練された魔法感度が、自然の中での魔法の乱れを鋭く感じ取れる理由になる
3. **疲弊の具体性**: 「今日も8時間、ビルの魔法回路を調律した。肩と目の奥が重い」──短い描写で伝わる
4. **使い分けの根拠**: 魔法エネルギーの状態を感じ取れるからこそ、「ここでは使わない方がいい」と判断できる

### 都市パートの描写素材

| シーン | 描写の方向性 |
|--------|-------------|
| 出勤 | 整備された魔法インフラの中を通勤。快適だが、調律師の目には微細なズレが見えてしまう |
| 業務中 | 回路に手を当て、目を閉じ、エネルギーの流れを聴く。整った波形に直す。完璧に仕上げる。完璧に疲れる |
| 帰宅 | 自宅の魔法空調が完璧に調律された快適さ。その完璧さに、何も感じない |
| 休日 | 何もする気が起きない。魔法感覚を休めたいのに、都市の魔法インフラが常に「聞こえている」 |

## 性格・内面

### 確定方向
- 都会で知的労働・最適化・高精度・正解志向にさらされて疲弊している
- 自分の疲弊を完全には自覚していない（あるいは認めたくない）段階から始まる（有力案）
- 一人の時間を好む。社交が嫌いではないが、「回復」は一人で行う
- 自然の不便さ、美しさ、静けさを味わうことを好む

### 有力案：性格の方向性

| 要素 | 方向性 |
|------|--------|
| 表面的な性格 | 穏やか、寡黙寄り、真面目 |
| 内面 | 完璧主義的傾向、自己評価の基準が「成果」に偏っている |
| 変化の方向 | 「成果で測れない時間」を許容できるようになる |
| ユーモア | 自虐的というより、静かな観察眼からくるユーモア |

### 調律師としての性格的特徴（有力案）
- 職業的に「ズレを見つけて直す」人なので、日常でも無意識に周囲の不調和が気になる
- しかしそれは美徳であると同時に、「休めない」原因でもある
- 自然の中では、魔法のズレが「直すべきもの」ではなく「そのままでいいもの」になる──この感覚の転換が回復の核

## 魔法能力

### 確定事項
- 魔法強者すぎるわけではないが、平均よりはかなり上
- 偏差値60程度
- **強さの本質は、魔法の強度よりも、魔法と非魔法の使い分けにある**

### 調律師としての魔法特性（確定）
- **得意領域**: エネルギーの感知・微調整。パワーより繊細さ
- **感覚系寄り**: 魔法エネルギーの流れを「聴く」「感じる」能力が高い
- **出力は平均的**: 大きな魔法を発動する力は特別ではない

### 「使い分けの巧みさ」の具体化（確定）
- 調律師は魔法エネルギーの状態を常にモニタリングする訓練を受けている
- 自然の中で魔法環境が不安定なとき、**無理に使うと何が起きるか**を感覚的に理解できる
- だからこそ「ここでは使わない」という判断が、勘ではなく専門知識に基づいている
- この「切り替えの判断力」が、他のアウトドア愛好者にはない主人公固有の強み

### アウトドアでの魔法使用方針（有力案）
- 原則として使わない。不安定な環境で使うと逆に疲弊するため
- 緊急時（怪我・危険な天候変化等）は最小限使う
- 意図せず発動しかけることがある（都市の習慣が身体に染みついている）
- 回を重ねるうちに、「使わない」ことが自然になっていく

## 動機と変化のアーク

### 物語開始時点の状態
- 仕事は「できている」が、達成感や充足感がない
- 休日もなんとなく疲れている。回復しきらないまま月曜を迎える
- 具体的な不満や敵がいるわけではない──だからこそ、対処が難しい
- 調律師として優秀だが、「整えること」に疲れている

### アウトドアを始めるきっかけ（確定）

#### 最初の体験：衝動×偶然の看板

仕事帰り、あるいは休日の外出中に、たまたま「道具不要で楽しめるキャンプ施設」の看板を見かける。特に計画はない。何かに引かれるように立ち寄り、手ぶらキャンプを体験する。

この最初の体験で得るもの：
- 魔法インフラの整った都市から離れた場所の「静けさ」
- 自分の手で火を起こす、外で食事をする、という原始的な充足感
- 「また来たい」という、理屈ではない衝動

> **ポイント**: きっかけは衝動的で偶然。「正解を選んだ」のではなく「なんとなく寄ってみた」。これ自体がテーマ（正解じゃない時間の価値）を体現している。

#### 仕事の転換：出張調律部門への異動

最初の体験をきっかけにアウトドアへの関心が芽生えた主人公は、都市中心の案件を請け負う現在の部署から、**地方の各拠点を巡回して調律を行う出張部門**への異動を選ぶ。

| 項目 | 異動前 | 異動後 |
|------|--------|--------|
| 勤務形態 | 都市の大型施設を固定担当 | 地方の中小施設を巡回出張 |
| 魔法環境 | 整備された安定圏のみ | 安定圏〜やや不安定な郊外まで |
| 生活 | 毎日同じオフィス・同じ街 | 各地を転々。移動が多い |
| アウトドアとの接点 | なし | 出張先の周辺で週末や空き時間にアウトドア |

この異動が物語に与える効果：
1. **連鎖型探訪の構造的エンジン**: 仕事で各地に行く → その土地の自然を探索する、という流れが毎セット自然に成立する
2. **目的地の情報源が多様化**: 出張先の地元民、施設の管理人、移動中に見た景色、土地の文献──情報源が仕事を通じて広がる
3. **都市パートの変化**: 異動前（序盤）は同じ都市の描写、異動後は各地の小さな町の描写になり、場面に変化が出る
4. **主人公の能動性**: 異動は命令ではなく**自分で選ぶ**。「最初の体験」に動かされて、環境を自分で変えた、という行動

#### 異動のタイミング（有力案）
- 第1章（1〜5話）: 都市での日常 → 看板 → 手ぶらキャンプ初体験 → 帰還 → 何かが変わった感覚
- 第2章序盤（6〜7話あたり）: 自分で装備を揃えて近郊へ再訪 → 出張部門の存在を知る → 異動を決意
- 第2章中盤以降: 出張先でのアウトドアが始まる → 連鎖型探訪のサイクルが回り始める

> **状態**: きっかけの構造は **確定**。具体的な施設の描写、看板を見る状況、異動の経緯の細部は **未確定**。

### 変化の方向（確定）
- 「ちゃんと生きている感覚」を取り戻していく
- 大きな覚醒や転換ではなく、小さな気づきの積み重ね
- 最終的に、都市生活を捨てるのではなく、**自分なりのバランスを見つける**

## 設定上の注意点

### 破綻リスク
- **「疲弊した社会人」だけだと、キャラクターが薄い**
  - → 調律師としての具体的なスキル・成果・プライドを描き、「有能だからこその疲弊」を示す
  - → 単なる弱者救済の物語ではなく、能力者の再調整の話
- **「偏差値60」が実感として伝わらないリスク**
  - → 序盤の調律シーンで同僚との比較、難易度の異なる案件への対応で位置づけを示す
- **主人公が受動的になりやすい構造**
  - → 目的地を自分で選ぶ行為、食材調達・狩猟の能動性で補う
  - → 調律師の「感じ取る力」を自然の中で能動的に使う描写（危険の察知、天候の予測など）
- **調律師の「魔法ノイズが聞こえる」設定が強すぎると、障害者ものに寄るリスク**
  - → 「うるさい」のではなく「気になる」程度に留める。日常生活は問題なく送れている
