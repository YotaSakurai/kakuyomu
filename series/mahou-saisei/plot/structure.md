## 構造の定義

### 基本サイクル（2〜5話で1セット）

```
目的地を知る → 準備・出発 → 道中のアウトドア → 到着・体験 → 次の目的地を見つける
     ↑                                                              │
     └──────────────────────────────────────────────────────────────┘
```

各セットの中に「食材調達→調理→食事」「偶然の出会い」「内面の変化」が自然に含まれる。
目的地が変わるたびに環境・食材・人が変わり、バリエーションが構造的に確保される。

### 目的地の情報源（確定：多様な経路）

主人公が **自分で行き先を選ぶ** 物語。誰かに導かれるのではなく、様々な情報源から自分で決める。

| 情報源 | 例 |
|--------|-----|
| 人から聞く | 山で出会った人の話、地元民の助言 |
| 教科書・文献 | 学生時代に学んだ場所、図鑑に載っていた地形 |
| 自分の知識 | 以前から知っていた有名な場所、仕事で耳にした地名 |
| 地図・古い記録 | 地図上で気になった場所、山小屋のノート |
| 前回の体験から | 山頂から見えた湖、前回行けなかった分岐の先 |

情報源を1種類に固定しない。セットごとに変えることで、展開が単調にならない。

```
    │            │            │              │              │
 魔法：安定    やや不安定    不安定       非常に不安定    ほぼ使えない
 難易度：低      中          中〜高          高            最高
```

```
仕事:    固定 → 異動 → 出張 → 超越 → 離れる → 戻る
```

## 最終到達地点（確定：Y主軸、X・Z微量）

### 核心（Y）：「ただの自然」

たどり着いた先にあるのは、ただの自然。
壮大な秘密も、特別な力も、何もない。
風が吹いていて、水が流れていて、火を起こせば温かい。
そこにあるのは「ここに来るまでに自分が変わった」という事実だけ。

**答えは目的地にはない。道中にあった。**

### 添え物（X）：魔法の希薄さ
- その場所はたまたま魔法が非常に届きにくい
- しかしそれは「特別な場所」だからではなく、単に地理的条件の結果
- 主人公にとっては、もはや魔法がなくても困らない自分がいることの確認

### 添え物（Z）：かすかな痕跡
- 古い焚き火の跡がある。使い込まれた道具が残っている
- かつて誰かがここに来て、同じように火を焚いた
- それが誰かは分からない。分からなくていい
- 主人公は自分の火を起こし、同じ風景を見る

### 描写の方針
- 到達の瞬間を劇的にしない
- 「ここだったのか」ではなく「ああ、いい場所だな」くらいの温度
- 物語のクライマックスは到達そのものではなく、到達後の静かな夜

## 章構成（確定）

### 仕事とアウトドアの関係の変遷

```
第1章:  仕事＝都市固定  /  アウトドア＝偶然の体験（看板→手ぶらキャンプ）
第2章:  仕事＝出張部門へ異動  /  アウトドア＝出張先の周辺で再開
第3章:  仕事＝各地を巡回  /  アウトドア＝出張のついでに本格化
第4章:  仕事＝各地を巡回  /  アウトドア＝仕事を超えて私的な遠出
第5章:  仕事の範囲を超えて  /  アウトドア＝自分の意志で最奥部へ
最終章: 仕事と自然のバランス  /  アウトドア＝生活の一部として定着
```

### 第1章：最初の一歩（1〜5話）── 初夏（5〜6月）

| 項目 | 内容 |
|------|------|
| **目的地** | 都心から日帰り〜1泊圏の手ぶらキャンプ施設（モデル地域：奥多摩・秩父・丹沢あたり） |
| **魔法環境** | 安定圏の縁。施設内は調律済みだが、少し外れると揺らぎがある |
| **食** | 施設提供の食材＋焚き火で焼くだけの単純な料理。「外で食べると味が違う」の発見 |
| **出会い** | 施設スタッフ程度。基本的に一人の体験 |
| **主人公の変化** | 「魔法が聞こえない場所がある」→ 都市に戻って、初めて自分の疲弊を自覚する |
| **次への引き** | 施設の周辺を散歩中に見えた山並み／パンフレットに載っていた渓流の写真 |

#### 話の流れ（確定）

```
第1話: 調律業務→帰路で看板→衝動的に施設へ→初めての焚き火→魔法の静寂。第1話内で感覚の転換を体験させる
第2話: 施設での夜と翌朝。星空、朝の森。施設の外を散歩し「調律されていない自然」を体感する
第3話: 帰還。都市の魔法インフラが「うるさい」と感じる自分に気づく。仕事は変わらないのに何かが違う
第4話: 翌週。アウトドアショップに立ち寄る。装備を揃え始める。次はどこへ行こうか考え始める
第5話: 自分の装備で近郊の山へ。第1章の締めくくりと第2章への橋渡し
```

### 第2章：足を伸ばす（6〜13話）── 夏（7〜8月）

| 項目 | 内容 |
|------|------|
| **目的地①** | 近郊の渓谷。自分の装備で初の本格キャンプ（モデル地域：山梨・長野の渓流） |
| **目的地②** | 出張先近くの高原・湖畔（モデル地域：信州・上越あたり） |
| **魔法環境** | やや不安定。「あ、ここでは火の魔法がうまくいかない」を初体験 |
| **食** | 渓流釣り（初挑戦・失敗含む）、山菜採り入門。焚き火調理の試行錯誤 |
| **出会い** | ①渓流で黙々と釣りをしている地元の人。帰り際に一言ヒントをくれる ②出張先の施設管理人。地方のインフラ事情を教えてくれる |
| **主人公の変化** | 「自分の手でやる」喜びの発見。出張部門への異動を決意する |
| **次への引き** | 施設管理人から「秋になったらあの山がいい」と聞く／古い山岳誌で気になる記述を見つける |

#### 転換点
第2章中盤（8〜9話あたり）で出張部門への異動を決意・実行。以降、仕事で各地に行ける環境が整う。

#### 話の流れ（暫定）

```
第6話:  前章で気になった渓流を目指す。自分の装備で出発。緊張と期待
第7話:  渓谷到着。テント設営に苦戦。山菜を見つけるが、調理はぎこちない
第8話:  渓流釣りに挑戦。地元の釣り人と無言の並び釣り。魚は釣れない
第9話:  翌朝、ようやく一匹。焚き火で焼く。釣り人が「上流にもっといい場所がある」と一言。帰還
第10話: 都市。出張部門の存在を知る。仕事をこなしながら、渓流のことが頭をよぎる。異動を決意
第11話: 出張先（高原の施設）で調律業務。仕事後、湖畔を散歩。魔法の揺らぎを初体験
第12話: 湖畔でのキャンプ。施設管理人と会話。「秋のこの辺りは別世界ですよ」
第13話: 出張生活の始まり。感覚が少し変わっている自分に気づく。次の計画を立て始める
```

### 第3章：深入り（14〜22話）── 秋（9〜11月）

| 項目 | 内容 |
|------|------|
| **目的地①** | 東北の深い森。出張ついでに足を伸ばす（モデル地域：山形・秋田の山間部） |
| **目的地②** | 山岳地帯の稜線・古道（モデル地域：北アルプス周辺、もしくは奥秩父の古道） |
| **目的地③** | 海辺の小さな集落（モデル地域：日本海側の漁村。山だけでなく海の変化を入れる） |
| **魔法環境** | 明確に不安定。魔法を使おうとして疲弊する場面あり。「使わない方が楽」と体で覚える |
| **食** | きのこ狩り（判別の難しさ）、木の実、保存食作り。海辺では地元の魚介。料理の腕が上がる |
| **出会い** | ①山の中で一人暮らしに近い生活をしている老人。魔法をほとんど使わない暮らし ②古道で出会う同世代の女性登山者。動機は異なるが、山への想いで通じ合う |
| **主人公の変化** | 魔法なしの自分に自信がつく。同時に「なぜこんなに心地いいのか」をまだ言語化できない |
| **次への引き** | 老人が「冬の山は別の顔を見せる」と言う／古道の途中で見た、地図にない分岐 |

#### この章の機能
人との繋がりが深まる章。後半で再登場する人物の「種」を撒く。目的地が3箇所あり、最も密度の高い章。

| 項目 | 内容 |
|------|------|
| **目的地** | 都市への帰還 → 最初の手ぶらキャンプ施設への再訪 |
| **魔法環境** | 全域。都市の調律された魔法が「うるさい」のではなく「懐かしい」と感じる |
| **食** | 都市の食事と、キャンプ施設での一年前と同じシンプルな焚き火飯。同じ料理が、全く違う味 |

#### 最終話の温度
大団円ではない。日常に戻った主人公が、次の週末のことを考える程度の、静かな終わり方。

## 設計上の注意点

### この構造の強み
1. 目的地が変わるたび読者に新鮮さを提供できる
2. 「次はどこへ行くのか」が自然な引きになる
3. 近郊→奥地の進行がテーマの深化と一致する
4. 季節の一年サイクルが主人公の再生と同期する
5. 最終到達地点が「ただの自然」であることが、テーマを裏切らない
6. 最終章で原点に戻ることで、変化が際立つ

### この構造のリスクと対策
| リスク | 対策 |
|--------|------|
| 場所のカタログ化（旅行ガイドになる） | 各目的地で主人公の内面変化を必ず描く |
| 都市パートが退屈になる | 帰還後の感覚の変化を描く。異動の過程もドラマになる |
| 後半の出会いが減り単調になる | 第4章で過去の人物と再会。第5章は「一人」であることに意味を持たせる |
| 50話分の目的地バリエーション | 地形（山・川・湖・海・高原・雪原）×季節×食材で組み合わせ済み |
| 第5章が静かすぎて読者が離れる | 第4章の山小屋ノートの伏線で「この先に何があるか」の引きを残す |
| 季節進行と話数が合わない | 各章の話数は暫定。執筆時に調整可能 |
