## アウトドアの位置づけ

### 確定事項
- アウトドアは単なる野外趣味ではない
- **魔法社会の過剰最適化から距離を取る行為** として価値を持つ
- 自然の中では魔法が不安定、あるいは使いすぎると逆に疲れる
- あえて魔法に頼らない時間が「回復」になる

### アウトドアが提供する価値（確定）
| 価値 | 説明 |
|------|------|
| 不確実性 | 天候・地形・出会い──コントロールできないものとの接触 |
| 身体で世界に触れる感覚 | 魔法補助なしで五感を使う体験 |
| 五感の回復 | 都市の魔法ノイズから解放された感覚の鋭敏化 |
| 非効率の許容 | 「最適解」を求めなくていい時間 |
| 魔法や都市ノイズからの解放 | 環境エネルギーの静けさ |
| 本物の火、水、食事、静けさの再発見 | 魔法を介さない直接体験 |

## 現代キャンプとの対応関係

この世界のアウトドアは、現実世界のキャンプ・アウトドア文化の構造を魔法社会にスライドさせたもの。

| 現実のキャンプ文化 | この世界での対応 |
|------------------|----------------|
| デジタルデトックス | 魔法デトックス |
| 電気・ガスを使わない調理 | 魔法を使わない調理 |
| 焚き火の癒し | 自分で起こした「本物の火」の価値 |
| 不便を楽しむ思想 | 魔法なし生活の「豊かな不便さ」 |
| ソロキャンプの孤独と自由 | 魔法接続から切れた静寂と自由 |
| アウトドア料理のこだわり | 魔法なしの食材調達・調理 |
| 自然の中での偶然の出会い | 同じく（魔法が使えない環境での人間関係） |

## アウトドアの社会的位置づけ

### 確定：昔からある文化だが再評価中

- 魔法が普及する以前、人は自然の中で暮らしていた。その生活様式は「古い文化」として残っている
- 魔法社会の成熟とともに、一部の人がその価値を再発見し始めている
- 大きなブームではないが、「魔法を使わない時間」を求める人が静かに増えている
- 手ぶらキャンプ施設のような入門的サービスが出てきている段階
- 主人公もその流れの中の一人だが、やがてより深い領域に踏み込んでいく

この設定が物語に与える効果：
- 第3章の老人は「昔からこの暮らしを続けている人」として自然に登場できる
- 第4章の山小屋ノートは「過去にも同じことを求めた人がいた」という歴史の厚み
- 手ぶらキャンプ施設が「再評価の入口」として存在する説得力
- 主人公が変人扱いされない程度には社会的認知があるが、主流ではない

## 描写の指針

### 重視する感覚描写
- **視覚**: 焚き火の揺らめき、星空、朝靄、木漏れ日
- **聴覚**: 沢の音、風の音、鳥の声、火のはぜる音、静寂
- **嗅覚**: 煙、土、雨上がり、木の香り、料理の匂い
- **触覚**: 冷たい水、火の温もり、木の手触り、風
- **味覚**: 焚き火料理の味、山の水、野草の苦み

### トーンの指針
- 大袈裟な感動ではなく、静かな気づき
- 「美しい」と直接書くのではなく、感覚描写で読者に感じさせる
- アウトドアの「失敗」も丁寧に描く（火がつかない、雨に降られる、食材が予想外の味）
- 成功体験のカタルシスではなく、プロセスそのものの価値を描く

## 設定上の注意点

### 破綻リスク
- **「魔法が不安定な自然」の描写が不足すると、ただのキャンプ小説になる**
  - → 魔法社会の日常を先に描き、その対比としてアウトドアを描く必要あり
- **アウトドア描写が「正しい生き方の説教」に見えるリスク**
  - → 主人公自身も迷っている、完全な答えは持っていない、という描写が必要
  - → 都市生活を否定するのではなく、「バランス」としてのアウトドア
- **食材調達・狩猟の描写が雑だと、リアリティが崩れる**
  - → 取材・調査が必要な領域。具体的な動植物の知識が求められる
